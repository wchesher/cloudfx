# Team hub contract (backend and frontend build against this)

lumin8r's website is the convergence point: everything the team does today is reachable from it.

## Pages
- `GET /` -> `static/home.html`: public front door. What lumin8r is, two doors: "Build your file" (`/app`) and "Team" (`/team`). Use limits and the privacy line. No data.
- `GET /app` -> `static/index.html` (the employee bench, unchanged). `GET /` no longer serves it.
- `GET /team` -> `static/team.html`: the team hub (works signed-out: shows the code prompt).
- `GET /paste` -> `static/paste.html` (team-gated like every /api/station/* route).

## Team gate
- Env `LUMIN8R_TEAM_CODE` (set on the box with `update-lumin8r --set-key LUMIN8R_TEAM_CODE`).
- `POST /api/team/login {code}` -> 200 `{ok:true}` and sets cookie `lumin8r_team=<HMAC of code with a per-process random key>; HttpOnly; SameSite=Strict; Path=/` (add `Secure` when the request came through https: header `X-Forwarded-Proto: https`). Wrong code -> 401 `{error}`; after 5 wrong codes from one IP in 10 minutes -> 429.
- `POST /api/team/logout` clears the cookie.
- `GET /api/team/me` -> `{signed_in: bool, mode: "local"|"code"}`.
- If `LUMIN8R_TEAM_CODE` is unset: when env `LUMIN8R_REQUIRE_TEAM_CODE=1` (the box's unit sets it) every team route answers 503 `{error:"team code not set on this box: update-lumin8r --set-key LUMIN8R_TEAM_CODE"}`; otherwise (a laptop) team routes are open and `me` says `mode:"local"`.
- Gated: `/paste`, `/api/station/*`, `/api/team/*` (except login, logout, me). Not signed in -> 401 `{error:"team sign-in required"}`.

## People (step 1: collect kits)
- `GET /api/team/people` -> `{people:[{code, has_build, has_test, build_problems:[...], pasted:{A:n, B:n}, total_runs:n, interview}], variants:[...], questions:[{id,type}]}`. `interview` is null without `voice_transcript.json`, else `{present:true, used:bool, source, interview_minutes, employee_answers, leakage_guard:"passed"|"refused"|null, leakage_hits:[{turn, test_id}|{turn, test_answer, shared_8_word_runs}], problem:string|null}` (never transcript text). With a used transcript, `total_runs` and the paste station also count the `<variant>_plus_interview` runs (kit plus interview arm, Kit Section 11; `docs/alternative-intake.md`).
- `POST /api/team/people {code, build, test}` (`build`/`test` are the organizer JSON objects; `test` optional at upload) -> validates with `answers.parse_answers`, refuses a build that contains any held-out test ID (S02 S04 S06 W02 W04) or a test that contains build IDs, refuses a `code` not matching `^[A-Za-z0-9_-]{2,32}$` or not equal to `build.person_id`; saves under `MEFILE_PEOPLE_DIR/<code>/`. -> `{saved:true, problems:[...]}`.
- `POST /api/team/people/delete {code}` -> removes that folder (whole). -> `{deleted:true}`.
- `POST /api/team/voice {code, transcript}` (`transcript` is the reviewed `voice_transcript.json` object the interview page downloads) -> the person must already have `build.json` (else 404) and `test.json` (else 400). The transcript is cut to the fields intake reads, its `person_id` must be empty or equal `code` (it is set to `code`), it is validated with `intake.parse_transcript` and checked by `experiment.leakage_check` against that person's test.json, then written to `MEFILE_PEOPLE_DIR/<code>/voice_transcript.json` (replacing any earlier one). -> `{saved:true, interview:{...same shape as in GET /api/team/people}}`. Guard trip -> 400 `{error, leakage_guard:{passed:false, test_ids_found:[{turn, test_id}], quotes_found:[{turn, test_answer, shared_8_word_runs}]}}`, never the matched words. Other refusals -> 400 `{error}` (unknown source, no employee answers, another person's transcript).

## Run, judge, results (steps 2-4)
- Paste runs: the existing paste station (`/paste?model=A|B`).
- `POST /api/team/run {model:"A"|"B", overwrite?:bool}` -> answers every missing run of that model through its API and saves into `llm_a.json` / `llm_b.json` exactly like the paste station; streams nothing; returns `{answered:n, kept:n, errors:[...]}`. LLM A: Claude API (`runner.ask`), 503 without `ANTHROPIC_API_KEY`. LLM B: OpenAI Responses API (`openai_runner.ask`, same two-turn protocol), 503 unless both `OPENAI_API_KEY` and `MEFILE_LLM_B_MODEL` are set. A saved answer (a person's paste) is never replaced unless `overwrite` is `true` (anything but a boolean -> 400); `kept` counts pastes that landed while the API was answering. Any other model -> 400.
- `GET /api/team/people` and `GET /api/team/final` add `llm_api: {A:{configured, model, effort}, B:{configured, model, effort}}` (never a key); the run and final stations show "Run LLM B (GPT) by API" only when `B.configured`, and the paste station stays.
- `POST /api/team/experiment {judge:bool}` -> runs `experiment.run_experiment` in manual mode (pasted A and B; judge only when `judge` and a judge model distinct from LLM A is configured) -> `{summary:[...], results_md:"<markdown text>"}`, plus `comparison` (kit only vs kit plus interview, judge scores included; also `DATA/team/experiment/comparison.json`/`.md`) when a person has a used transcript. A transcript that trips the leakage guard makes this 400.
- `GET /api/team/results` -> last `{summary, results_md}` or `{summary:[], results_md:""}`.
- `POST /api/team/ratesheet` -> builds the blind rating sheet from all pasted responses (judge.agreement) and returns `{url:"/api/team/files/ratesheet.html"}`; `GET /api/team/files/<name>` serves files from `DATA/team/` (names `[A-Za-z0-9._-]+` only).
- `POST /api/team/agreement {ratings:[<ratings json objects>]}` -> runs agreement against the last evaluations -> `{agreement_md:"..."}`.

## Final (step 5: freeze-day, 4:30-5:30)
- `POST /api/team/final/inputs {build, questions}` -> saves to `DATA/final/`, runs the converter (full scope, evidence_first unless env `LUMIN8R_FINAL_VARIANT`), refuses if the gate fails -> `{markdown, gate, questions:[{id,type,prompt,word_limit}], runs:[{run_id:"TEAM-A-<qid>"|"TEAM-B-<qid>", model, question_id}]}`. Team prefix from env `LUMIN8R_TEAM_NAME` (default `TEAM`).
- `GET /api/team/final` -> current final state: `{markdown|null, questions, runs:[{run_id, model, question_id, answer}], evaluations_ready:bool}`.
- `POST /api/team/final/answer {run_id, text}` -> saves into `DATA/final/responses.json` (comparison format).
- `POST /api/team/final/run {model:"A"|"B", overwrite?:bool}` -> answers that model's final runs through its API with the final `me.md` as message 1 and each question as message 2, saving into the same `DATA/final/responses.json` (so judging and the bundle are unchanged) -> `{answered, kept, errors}`. 409 before the inputs are saved; 503 when the model's API is not configured. Pasted answers are kept unless `overwrite` is `true`.
- `POST /api/team/final/judge {test, comparisons}` -> saves both, runs the judge over our 8 + the 12 comparison responses (blind), writes `DATA/team/evaluations.json` and `.md` -> `{evaluations_md, counts:{ok, judge_error}}`. 503 if no distinct judge model/key. `generation_models_under_test` lists the LLM A model and, when set, `MEFILE_LLM_B_MODEL`: LLM B is under test, never the judge.
- `GET /api/team/final/bundle` -> a zip of me.md, responses.json, evaluations.json/.md, results.md (the submission set).

## Docs

## Judge self-check (Common Kit section 9: "Report at least one case where it fails")
- `POST /api/team/selfcheck` -> runs `judge.eval_corpus.run_judge_selfcheck` with the real judge (`AnthropicJudgeBackend`; the fictional DEMO01 corpus only) -> `{passed, total, probes:[{name, expectation, result, passed, detail}], selfcheck_md, judge_model_requested, judge_models_served, at}`. Writes `DATA/team/selfcheck.json` (with the raw evaluations) and `selfcheck.md`. 503 `{error}` with no `ANTHROPIC_API_KEY` or on `JudgeConfigError` (for example the judge model equals the LLM A model).
- `GET /api/team/selfcheck` -> the last run without the raw evaluations, or `{passed:0, total:0, probes:[], selfcheck_md:""}`.
- Team page: judge station, "Can the judge tell good from poor?". `selfcheck.md` goes into the submission bundle.

## Provenance of runs (Common Kit section 9: "Record the model versions and how you loaded the file")
- `POST /api/station/answer` and `POST /api/team/final/answer` accept optional `model_shown` (text, the model name the chat window displayed; whitespace collapsed, at most 120 characters; anything but text -> 400). Each saved record carries `model_shown` (when given), `loading` and `pasted_at`. Paste-station records also carry `source:"paste"`.
- `loading` for pasted runs: `"new chat, memory and custom instructions off; me.md as message 1, question as message 2"` (no-profile paste runs: `"...; question as the only message"`). Runs answered by `POST /api/team/run` or `POST /api/team/final/run` carry `source:"api"`, `model_served` (the response's model), `model_requested`, `effort` (when the answerer reports them) and an API loading string (Claude: `"Claude API (runner.ask): ..."`; OpenAI: `"OpenAI Responses API (openai_runner.ask): ..., no instructions, store false"`).
- Pages: the paste station has a required-once field "Model name shown in the chat window", stored per model in `localStorage` (`lumin8r.model_shown.A|B`) and sent with every save; the final station has the same field for LLM A and LLM B (same keys), and refuses to save an answer until it is filled.
- `GET /api/team/final` adds `model_shown: {A, B}` (the last name saved with a final answer, to prefill another browser).
- `GET /api/team/final/bundle` adds `provenance.json` (`{loading_protocol, final:{A,B}, team_runs:{A,B}, judge, warnings, generated_at}`; per model: `model_shown[]`, `runs`, `pasted_runs`, `api_runs`, `loading[]`, `model_served[]`), `selfcheck.md` when run, `writeup.md` when `docs/writeup.md` exists, and `README.md` (run instructions).

## Questioning claims (employee bench, `/app`)

## Admin (the operator's console, `src/mefile/admin.py`)
- `GET /admin` -> `static/admin.html`. Same gate as `/team`: the `lumin8r_team` cookie, `LUMIN8R_TEAM_CODE`, and 503 on a box (`LUMIN8R_REQUIRE_TEAM_CODE=1`) with no code. Signed out, the page shows the team code prompt and signs in through `POST /api/team/login`. Every `/api/admin/*` route: 503 unconfigured, 401 `{error:"team sign-in required"}` signed out.
- Never returned by any admin route: a key's value, the team code, the cookie, a consent token or a token hash. `MEFILE_JUDGE_MODEL` is a model name and is shown.
- `GET /api/admin/overview` -> `{release (env LUMIN8R_RELEASE or "unknown"), host (env LUMIN8R_HOST or ""), started_at, uptime_seconds, keys:{ANTHROPIC_API_KEY, ELEVENLABS_API_KEY, ELEVENLABS_AGENT_ID, LUMIN8R_TEAM_CODE: bool}, judge_model (or null), judge_ready (a key and a judge that constructs, distinct from LLM A), judge_note (why not), twin_ready, voice_ready, settings:{variants, team_name, final_variant, people_dir, data_dir, consent_dir, require_team_code}, counts:{people, consents_active, consents_withdrawn, pasted_runs_A, pasted_runs_B, final_responses, evaluations_ready}}`.
- `GET /api/admin/consent` -> `{people:[{person_id, state:"active"|"withdrawn", purposes, ai_services, share_with, first_at, last_at, events}], entries_total, unreadable_lines, ledger}` from the append-only ledger (`MEFILE_CONSENT_DIR/ledger.jsonl`); state is the latest consent or withdrawal; purposes and services are the latest consent's.
- `GET /api/admin/consent/export` -> the ledger as an `application/x-ndjson` attachment, every `*token_sha256` field removed (lines that are not JSON objects are left out; header `X-Lumin8r-Unreadable-Lines` counts them). The ledger is never edited or deleted from the admin.
- `GET /api/admin/people` -> `{people:[{code, has_build, has_test, kit_minutes (build.json's, or null), pasted:{A,B}, model_shown:{A:[...],B:[...]}, voice_transcript (voice_transcript.json present), bytes, last_modified}], people_dir, total_bytes}`.
- `POST /api/admin/people/delete {code}` -> `{deleted:true}`; the team hub's delete (same code validation, 400 on a bad code, 404 on no such person).
- `POST /api/admin/purge {scope, confirm}`: `scope` is `people` (every entry in the people folder), `outputs` (everything in `DATA/team` except the final evaluations, and `DATA/experiment`) or `final` (everything in `DATA/final`, and `DATA/team/evaluations.json`/`.md`). `confirm` must equal exactly `"DELETE " + scope.upper()` (`DELETE PEOPLE`, `DELETE OUTPUTS`, `DELETE FINAL`), otherwise 400 and nothing is deleted. The folders themselves stay. -> `{scope, deleted:[paths relative to the data folder], kept_consent_ledger:true}`. Every target is a direct child of a configured folder, checked after resolving; a symbolic link is removed as a link and never followed; anything that is or holds the ledger folder is skipped; 409 when the people folder holds the data folder.
- `GET /api/admin/settings` -> `{settings:[{name, kind:"key"|"update"|"box", secret, set, value (null for a secret), default, about, command}], update_env}`. Keys change with `sudo update-lumin8r --set-key NAME`; update settings (`LUMIN8R_HOST`, `LUMIN8R_PORT`, `MEFILE_VARIANTS`, `LUMIN8R_TEAM_NAME`, `LUMIN8R_FINAL_VARIANT`) with `echo 'NAME=value' | sudo tee -a /etc/lumin8r/update.env && sudo update-lumin8r` (the value quoted for bash, which sources the file); box values are set by update-lumin8r and have no command.
- update-lumin8r hands the service `LUMIN8R_RELEASE` (the live release's revision), `LUMIN8R_HOST`, `LUMIN8R_PORT`, and `MEFILE_VARIANTS` / `LUMIN8R_TEAM_NAME` / `LUMIN8R_FINAL_VARIANT` when set in update.env, as `-e` on the container and `Environment=` in the unit. They are part of the container signature, so a changed value recreates the container (host mode: a changed unit restarts the service).
- Page: sections Health, Consent, Data, Settings, Danger zone (hash-routed: `#health`, `#consent`, `#data`, `#settings`, `#danger`). Lime actions: Health "Open the team hub", Consent "Download the ledger"; none elsewhere. Each purge is its own card with what it deletes and keeps, a typed phrase, and a red button that stays disabled until the phrase matches.
